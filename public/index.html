Automated UI and API testing for critical e-commerce flows.

ShopSure is a Playwright and TypeScript test framework that validates login, cart, checkout, and product API behaviour with maintainable page objects, reusable data, and CI-ready reporting.

Architecture

Built so tests read like business workflows.

pages/ LoginPage, InventoryPage, CartPage, CheckoutPage
fixtures/ Reusable public demo users
test-data/ Products and fictional checkout data
tests/ UI and API regression specs

Why this matters

Locators and browser actions live in page classes, while specs stay readable and focused on behaviour. That makes the framework easier to extend, debug, and explain in a technical interview.
