API

Architecture

Readable tests with reusable support layers.

The framework keeps test intent separate from browser mechanics. Page classes own locators and actions, while specs stay close to the business scenario being verified.

  • Page Object Model in pages/
  • Reusable users in fixtures/
  • Product and checkout data in test-data/
  • Grouped UI and API specs in tests/
  • HTML reporting and failure screenshots
  • GitHub Actions workflow for CI execution
